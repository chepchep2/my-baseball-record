# My Baseball Record

`마이베이스볼레코드` 프로젝트 저장소입니다.

현재 저장소는 제품 문서와 프론트엔드 초기 구현을 함께 관리합니다.
문서 읽기와 제품 방향 확인은 [`docs/README.md`](./docs/README.md)를 기준으로 합니다.

## Repository Structure

- `docs/`
  - PRD, 시나리오, 설계, 와이어프레임, 구현 계획 문서
- `frontend/`
  - Next.js 기반 프론트엔드 구현 위치
- `backend/`
  - 백엔드 구현 예정 위치
