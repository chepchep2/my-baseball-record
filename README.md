# My Baseball Record

`마이베이스볼레코드` 프로젝트 저장소입니다.

현재 저장소는 제품 문서, 프론트엔드, 백엔드를 함께 관리합니다.
문서 읽기와 제품 방향 확인은 [`docs/README.md`](./docs/README.md)를 기준으로 합니다.

## Repository Structure

- `docs/`
  - PRD, 시나리오, 설계, 와이어프레임, 구현 계획 문서
- `frontend/`
  - Next.js 기반 프론트엔드 애플리케이션
- `backend/`
  - Spring Boot 기반 백엔드 애플리케이션

## Start Here

- 문서 허브: [`docs/README.md`](./docs/README.md)

## Runtime

- 기준 배포 브랜치: `main`
- 프론트 배포: `https://app.mybaseball.cloud`
- 백엔드 배포: `https://api.mybaseball.cloud`

- 서비스 이름: `마이베이스볼레코드`
- 영문 이름: `My Baseball Record`
