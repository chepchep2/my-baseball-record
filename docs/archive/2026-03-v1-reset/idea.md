# Idea

## Working Title

- Korean: `마이베이스볼레코드`
- English: `My Baseball Record`

## One-line Description

사회인 야구 팀과 선수가 경기 기록을 쉽고 빠르게 남기고, 시즌 성적과 경기 결과를 관리할 수 있게 돕는 앱.

## Why This Project

- 사회인 야구 기록은 수기로 하거나 흩어진 도구로 관리되는 경우가 많다.
- 경기 결과, 선수 기록, 시즌 누적 성적을 한 곳에서 보고 싶다.
- 기록 입력과 공유가 쉬워야 실제 현장에서 계속 사용된다.
