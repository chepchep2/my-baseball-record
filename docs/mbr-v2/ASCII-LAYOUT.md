# My Baseball Record v2 ASCII Layout

## 목적

이 문서는 v2 화면을 텍스트 기반으로 빠르게 공유하기 위한 레이아웃 문서다.

## 1. 경기 생성

```text
[ 날짜 ]
[ 실제 달력 ]

[ 시간 시 ][ 시간 분 ]
[ 시/도 ][ 구/군 ]

[ 다음 ]
```

## 2. 기존 경기 후보

```text
[ 5/20 10:30 ]
[ 부산시 강서구 ]
[ 맥도A ]

[ 5/20 10:50 ]
[ 부산시 강서구 ]
[ 맥도B ]

[ N개의 경기가 더 있습니다. ]
[ 더 보기 ][ 새 경기 ]
```

## 3. 새 경기 생성

```text
[ 추천 구장 ]
[ 맥도A ][ 맥도B ][ 대저A ]

[ 직접 구장명 입력 ]
[ 맥도C                    ]

[ 기존 구장 선택 ][ 새 구장 추가 ]
```

## 4. 경기 정보

```text
[ 날짜 ][ 시간 ]
[ 지역 ][ 구장명 ]

- 조상우   인증 기록
- 김영훈   인증 전
- 서세홍   인증 전

[ 더 보기 ][ 내 기록 입력하기 ]
```

## 5. 내 기록 입력

```text
[ 타석 ][ 사사구 ]
[ 1루타 ][ 2루타 ]
[ 3루타 ][ 홈런 ]

[ 저장 ]
```

## 6. 전체 경기 목록

```text
[ 연도 ]
[ 월 ]

[ 2026-05-15 17:20 ]
[ 부산시 강서구 / 삼락A ]
[ 인증됨 ]

[ 2026-05-13 10:30 ]
[ 부산시 강서구 / 맥도A ]
[ 인증 전 ]
```

## 7. 경기 기록 상세

```text
[ 날짜 ]
[ 시간 ]

[ 타율 ][ 출루율 ]
[ 장타율 ][ OPS ]

[ 타석 ][ 사사구 ]
[ 1루타 ][ 2루타 ]
[ 3루타 ][ 홈런 ]

[ 경기 정보로 ][ 삭제 ]
```
