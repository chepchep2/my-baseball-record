# My Baseball Record v2 Screen Design

## 1. Goal

이 문서는 My Baseball Record v2의 실제 화면 구조와 화면별 책임을 모바일 웹 기준으로 정의한다.

v2는 v1의 빠른 입력 성격을 유지하되,
기록 입력 전에 경기 단위를 먼저 선택하거나 만들게 하는 구조를 추가한다.

## 2. Screen Design Principles

### 1. Mobile Web First

모든 화면은 스마트폰 세로 화면 기준으로 설계한다.
작은 화면에서도 지금 무엇을 해야 하는지 바로 이해할 수 있어야 한다.

### 2. 경기 화면을 허브로 본다

기존 경기 선택이든 새 경기 생성이든,
먼저 경기 화면으로 이동한 뒤 거기서 기록 입력으로 들어간다.

### 3. 정보는 가볍게, 흐름은 명확하게

후보 경기 카드에는 최소 정보만 보여준다.
경기 화면에서는 경기 정보와 기록 리스트를 분리해 보여준다.

### 4. 기존 입력 감각 유지

날짜/시간 입력과 6개 타자 기록 입력의 감각은 v1과 최대한 비슷하게 유지한다.
v2는 완전히 새로운 입력 UI를 만드는 것이 아니라,
입력 앞쪽에 경기 선택 흐름을 추가하는 방식이다.

## 3. Screen List

v2의 핵심 화면은 아래 5개다.

1. 경기 생성 시작 화면
2. 기존 경기 후보 화면
3. 새 경기 생성 화면
4. 경기 화면
5. 내 기록 입력 화면

## 4. 경기 생성 시작 화면

### Role

- 경기 후보를 찾기 위한 최소 식별 정보를 받는다.

### Structure

- 날짜
- 시간
- 시/도
- 구/군
- `다음`

### Rules

- 날짜는 기존 인라인 달력 UI를 사용한다.
- 시간은 기존 시/분 선택 UI를 사용한다.
- 지역은 `시/도`, `구/군` 2단계 선택으로 간다.
- `김해시`처럼 일반적인 구/군 구조가 아닌 경우에도 두 번째 값은 그냥 `김해시`를 보여준다.

## 5. 기존 경기 후보 화면

### Role

- 사용자가 새 경기를 만들기 전에 먼저 기존 경기 합류 가능성을 확인하게 한다.

### Structure

- 기존 경기 카드 리스트
- `더 보기`
- `새 경기`

### Candidate Card

카드에는 아래 정보만 보여준다.

- 날짜
- 시간
- 지역
- 구장명

### Rules

- 후보 탐색 기준은 같은 날짜 + 입력 시간 기준 `±30분`
- 기본 탐색 범위는 같은 `구/군`
- `더 보기`는 더 넓은 범위 탐색으로 확장한다.

## 6. 새 경기 생성 화면

### Role

- 기존 후보가 없거나 사용자가 직접 새 경기를 만들고 싶을 때 사용한다.

### Structure

- 추천 구장 목록
- 직접 구장명 입력
- 유사 구장 경고
- `기존 구장 선택 / 새 구장 추가`

### Rules

- 해당 지역의 기존 구장 추천 목록을 먼저 보여준다.
- 직접 입력 시 유사 이름이 있으면 명시적으로 선택하게 한다.
- 운영자 수동 정리 없이도 입력 시점에 중복을 최대한 줄이는 것이 목표다.

## 7. 경기 화면

### Role

- 경기 단위 허브
- 현재 기록 상태 확인
- 기록 입력 진입점
- 기록 인증 진입점

### Structure

- 날짜
- 시간
- 지역
- 구장명
- 기록을 남긴 사람 리스트
- `더 보기`
- `내 기록 입력하기`

### Rules

- 생성자나 기록 참여자가 아니어도 경기 화면과 기록 리스트는 볼 수 있다.
- 인증은 생성자 또는 기록 참여자만 가능하다.
- 현재 사용자가 기록이 없으면 `내 기록 입력하기`를 보여준다.

## 8. 내 기록 입력 화면

### Role

- 현재 경기 안에서 사용자 자신의 타자 기록 1개를 입력한다.

### Structure

- v1과 같은 6개 타자 기록 입력 UI
- 저장 액션

### Rules

- 한 사용자는 한 경기에서 타자 기록 1개만 가진다.
- 저장이 완료되어야 그 사용자를 참여자로 본다.
- 투수 기록은 1차 범위에서 제외한다.

## 9. Verification Presentation

### Role

- 기록 신뢰도를 최소 수준으로 보여준다.

### Rules

- 기록 카드에는 인증 여부만 표시한다.
- 인증 수는 화면에 보여주지 않는다.
- 1명이라도 인증하면 `인증 기록`으로 표시한다.
