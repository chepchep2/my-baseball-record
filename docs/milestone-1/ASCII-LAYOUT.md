# My Baseball Record v1 ASCII Layout

## 1. Main Screen

```text
┌─────────────────────────────┐
│  [올해 시즌] [통산]          │
│ ┌───────────────────────┐   │
│ │ 타율    .280           │   │
│ │ OPS     .750           │   │
│ │ 안타    24             │   │
│ │ 출루율  .350           │   │
│ │ 장타율  .400           │   │
│ └───────────────────────┘   │
│                             │
│ 최근 경기 기록 리스트        │
│ ┌─────────────────────┐     │
│ │ 3/22 14:10          │     │
│ │ 타석 4 안타 1 .333   │     │
│ ├─────────────────────┤     │
│ │ 3/15 09:30          │     │
│ │ 타석 5 안타 2 .500   │     │
│ └─────────────────────┘     │
│                         [＋]│
└─────────────────────────────┘
```

최근 경기 기록 리스트는 최대 2개까지만 노출한다.

## 2. Entry Flow

입력 플로우는 총 4단계다.

- 1 / 4: 날짜 + 시간
- 2 / 4: 타석 + 사사구
- 3 / 4: 1루타 + 2루타
- 4 / 4: 3루타 + 홈런 + 저장

모든 단계는 모바일 웹 기준으로 스크롤 없이 끝나야 한다.
기록이 0건인 사용자는 매번 이 입력 플로우부터 시작한다.

## 10. Notes

- 메인 화면은 단일 화면 구조를 사용한다.
- 기록이 0건이면 매번 메인보다 입력 플로우를 우선 시작한다.
- 최근 경기 리스트는 읽기 전용이며 탭 동작이 없다.
- 날짜는 화면 안에 달력을 상시 펼치지 않고 선택 필드로 보여준다.
- 날짜 필드를 누르면 바텀시트 달력 UI가 열리고, 선택 후 같은 화면으로 돌아온다.
- 날짜 기본값은 오늘이다.
- 바텀시트 달력은 선택한 달의 한 달 전체를 보여준다.
- 연월은 헤더를 눌러 별도 선택한다.
- 시간은 `시`, `분`을 분리해 선택한다.
- `분`은 10분 단위를 사용한다.
- 시간 기본값은 현재 시각을 다음 10분 단위로 올린 값이다.
- 숫자 입력은 직접 입력 방식으로 간다.
- 모바일 웹에서는 숫자 키패드를 우선 유도한다.
- 단계에서 판단 가능한 오류는 즉시 보여주고 다음으로 넘어가지 못하게 한다.
- 오류가 있으면 `다음` 또는 `저장` 버튼은 비활성화된다.
- 저장 시점에는 전체 조합을 한 번 더 검증한다.
- 첫 단계 이탈 시에는 확인 모달을 보여준다.
