# My Baseball Record v1 PRD

## 1. Product Summary

My Baseball Record v1은 사회인 야구 선수가 경기 후 자신의 타자 기록을 빠르게 남기고,
시즌 및 통산 기록을 한 화면에서 확인할 수 있게 하는 개인 기록 관리 서비스다.

이 버전의 목표는 많은 기능을 한 번에 제공하는 것이 아니다.
사용자가 기록 입력을 부담스럽게 느끼지 않고 최소 1건 이상의 경기 기록을 남기게 만드는 것이 핵심이다.

## 2. Problem

사회인 야구 선수는 공식 기록이 남지 않거나 확인이 어려운 경기에서
자신의 기록을 직접 남겨야 하는 경우가 많다.

하지만 경기 직후에는 피로가 크고, 기록을 오래 기억하기도 어렵다.
이때 입력 과정이 길거나 복잡하면 기록을 남기지 않고 넘어가게 된다.

결과적으로 사용자는 기록을 남기고 싶어도 첫 기록 작성 자체를 미루거나 포기하게 된다.

## 3. Background And Product Lessons

기존 제품 구상과 멘토링, 실제 사용 경험을 통해 아래 교훈을 얻었다.

- 입력이 많으면 사용자는 이탈한다.
- 득점, 타점처럼 타인에 의해 결정되거나 기억이 어려운 기록은 1차 범위에서 빼야 한다.
- 사용자는 본인 타석 결과와 같은 핵심 기록은 비교적 기억할 수 있다.
- 입력을 재미있게 만드는 것보다 입력 자체를 줄이는 것이 더 효과적이다.
- 1차에서는 기록 관리의 완성도보다 첫 기록 작성 경험을 만드는 것이 더 중요하다.

## 4. Product Goal

v1의 목표는 `가입한 사용자가 첫 경기 기록을 남기게 하는 것`이다.

이 버전은 기록 관리의 완성형이 아니라,
사용자가 기록 입력을 시작하고 시즌/통산 누적 가치를 느끼게 하는 첫 단계에 집중한다.

## 5. Success Metric

핵심 성공 지표는 `경기 기록률`이다.

정의:
- 가입자 대비 1건 이상 경기 기록을 작성한 비율

목표:
- 가입자 10명 중 7~8명이 최소 1건 이상의 경기 기록 작성

보조 지표:
- 첫 기록 작성까지 걸리는 시간
- 기록 작성 완료율
- 기록 작성 중 이탈률

## 6. Target User

### Primary User

- 사회인 야구를 직접 하는 개인 선수
- 공식 기록이 없거나 불완전한 경기 기록을 직접 남기고 싶은 사람
- 경기 직후 또는 당일에 짧게 기록을 남기고 싶은 사람
- 복잡한 통계 관리보다 빠른 입력과 누적 확인을 우선하는 사람

### Excluded User

- 팀 관리자
- 리그 운영자
- 다른 선수 기록을 대신 입력하는 사용자
- 투수 기록 관리가 우선인 사용자
- 팀 운영 및 상세 분석 기능이 먼저 필요한 사용자

## 7. Scope

### In Scope

- 개인 선수 본인 기록만 관리
- 사회인 야구 타자 기록만 지원
- 카카오 로그인
- 경기 기록 생성
- 시즌/통산 요약 조회
- 최근 경기 기록 리스트 조회
- 기록 0건 사용자의 즉시 입력 유도

### Out of Scope

- 투수 기록
- 기록 수정 및 삭제
- 득점, 타점 입력
- 팀 운영 기능
- 리그 운영 기능
- 타인 기록 대리 입력
- 상세 타석 로그
- 음성 입력
- 기록 카드 공유
- 소셜 인증
- 전화번호 인증 확정

## 8. Product Principles

### 1. Reduce Input Fatigue

입력 피로를 최대한 낮춘다.
기록을 많이 받기보다 사용자가 끝까지 입력을 마치게 만드는 것이 우선이다.

### 2. No Scroll By Default

한 화면에서는 최대한 스크롤이 없도록 설계한다.
각 단계는 작은 화면에서도 한 번에 이해되고 끝나야 한다.

### 3. One Core Job

v1은 사회인 야구 타자 기록 1건을 빠르게 남기고 바로 누적 결과를 확인하게 하는 데 집중한다.

### 4. Show Value Immediately

입력 직후 시즌/통산 요약과 최근 경기 리스트에 기록이 반영되어야 한다.

## 9. Main Experience

### First-Time User

- 첫 가입 사용자는 기록이 0건이므로 메인 조회보다 기록 입력을 우선 시작한다.
- 가입 직후 바로 입력 플로우로 진입한다.

### Returning User

- 기록이 1건 이상 있는 사용자는 메인 화면으로 진입한다.
- 메인 화면에서 시즌/통산 요약과 최근 경기 기록을 바로 확인한다.
- 새 기록이 필요하면 `+` 버튼으로 입력을 시작한다.

### Zero-Record Rule

- 기록이 0건인 사용자는 매번 메인 화면보다 입력 플로우로 먼저 진입한다.

## 10. Input Model

### User Input Fields

사용자가 직접 입력하는 값은 아래 6개다.

- 타석
- 사사구
- 1루타
- 2루타
- 3루타
- 홈런

### Input Rules

- 빈값은 모두 `0`으로 처리한다.
- 모든 입력값은 `0 이상 정수`만 허용한다.
- 음수, 문자, 소수는 허용하지 않는다.
- 잘못된 값은 입력 단계에서 최대한 차단하고 저장 단계에서 다시 검증한다.

### Calculation Rules

- 타수 = 타석 - 사사구
- 안타 = 1루타 + 2루타 + 3루타 + 홈런
- 타율, 출루율, 장타율, OPS는 자동 계산한다.

### Validation Rule

- 타석은 사사구보다 작을 수 없다.
- 타수는 `타석 - 사사구`로 계산한다.
- 안타 종류의 합은 타수보다 클 수 없다.
- 현재 단계에서 판단 가능한 오류는 즉시 보여준다.
- 잘못된 값이 있으면 현재 단계 버튼은 비활성화된다.
- 저장 시점에는 전체 조합을 한 번 더 최종 검증한다.
- 남은 타수를 모두 사용한 순간 뒤 안타 필드는 잠기고 버튼은 바로 `저장`으로 바뀐다.

## 11. Game Identification

한 날짜에 여러 경기를 입력할 수 있으므로 경기 구분 정보가 필요하다.

v1은 아래 정보를 사용한다.

- 경기 날짜
- 경기 시각

### Date And Time Input

- 날짜는 달력으로 선택한다.
- 날짜는 입력 1단계 화면 안에서 인라인 달력으로 바로 선택한다.
- 달력은 실제 월간 달력처럼 `요일 행 + 7열 x 6행` 구조를 사용한다.
- 선택한 달의 날짜뿐 아니라 앞달/다음달 날짜도 흐리게 함께 보여준다.
- 앞달/다음달 날짜를 탭하면 해당 월로 이동하면서 그 날짜를 선택한다.
- 오늘 이후 날짜는 선택할 수 없다.
- 시간은 드롭다운으로 선택한다.
- 시간은 24시간제를 사용한다.
- `시`와 `분`은 나누어 선택한다.
- `분`은 10분 단위로 선택한다.
- 날짜 기본값은 오늘이다.
- 시간 기본값은 현재 시각 기준이다.
- 현재 시각은 현재 10분 단위로 내림해 기본 선택한다.
- 오늘 날짜를 선택한 경우 미래 시각은 선택할 수 없다.
- 오늘 이후 날짜는 선택할 수 없다.

## 12. Entry Flow

기록 입력은 2단계로 구성한다.
첫 단계에서 날짜와 시간을 정하고, 두 번째 단계에서 6개 값을 모두 입력한다.
다만 두 번째 단계에서는 한 번에 하나의 입력값에만 집중하게 하여 피로를 낮춘다.

입력 흐름은 아래와 같다.

1. 날짜 / 시간
2. 타석 / 사사구 / 1루타 / 2루타 / 3루타 / 홈런
3. 저장

각 단계는 아래 원칙을 따른다.

- 스크롤 없이 완료 가능해야 한다.
- 다음 단계로 명확하게 이동할 수 있어야 한다.
- 현재 몇 단계인지 진행 상태를 표시해야 한다.
- 사용자는 짧은 시간 안에 입력을 마칠 수 있어야 한다.
- 2단계에서는 6개 입력값을 모두 보여주되, 현재 활성 입력값 하나에만 포커스가 가야 한다.
- 사용자는 원하는 필드 카드를 눌러 해당 입력칸으로 다시 이동할 수 있어야 한다.
- 남은 타수가 0이 되면 뒤 안타 필드는 비활성화하고 즉시 저장 가능 상태로 전환해야 한다.

## 13. Main Screen

메인 화면은 단일 화면 구조를 사용한다.
탭바 기반의 다중 화면 구조 대신,
기록 확인과 새 기록 입력을 한곳에서 이어서 처리할 수 있어야 한다.

### Main Screen Structure

- 상단 범위 탭: `올해 시즌 / 통산`
- 핵심 지표 카드
- 최근 경기 기록 리스트
- 우하단 `+` 버튼

### Header Metrics

상단 카드에는 아래 8개 지표를 2열 4행으로 보여준다.

- 경기
- 타석
- 타율
- OPS
- 안타
- 사사구
- 출루율
- 장타율

### Recent Games List

최근 경기 기록은 리스트로 보여준다.
정렬 기준은 최근 입력 순이 아니라 실제 경기 시각(`playedAt`) 기준 내림차순이다.

- 최대 3개까지만 노출한다.
- 1줄: `월/일 시:분`
- 2줄: `타석 · 안타 · 타율`

예:
- `3/22 14:10`
- `타석 4 · 안타 1 · 타율 .333`

### List Interaction

- 최근 경기 리스트 아이템은 v1에서 탭 동작이 없다.
- 리스트는 읽기 전용 요약 정보로만 사용한다.
