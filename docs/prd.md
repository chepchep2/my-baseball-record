# PRD

## Product Summary

`마이베이스볼레코드`는 개인 선수 전용 모바일 웹 기록 관리 서비스다.

이 서비스의 목표는 사회인 야구 선수가 여러 곳에 흩어진 자신의 경기 기록을 한곳에 모으고,
시즌과 통산 단위로 계속 관리할 수 있게 만드는 것이다.

v1은 팀 운영 도구가 아니며, 리그 관리 도구도 아니다.
또한 경기 입력 자체만을 위한 입력 앱으로 정의하지 않는다.
제품의 중심은 `기록 확인과 누적 관리`이며, 경기 입력은 그 가치를 유지시키는 핵심 행동이다.

## Problem

사회인 야구 개인 선수는 공식 기록이 남는 경기와 그렇지 않은 경기를 모두 뛰는 경우가 많다.
하지만 자신의 전체 기록은 게임원, 리그 홈페이지, 개인 메모, 메시지 기록처럼 여러 출처에 흩어져 있다.

이 때문에 사용자는 아래 문제를 겪는다.

- 자신의 시즌 성적을 한 번에 보기 어렵다.
- 통산 기록을 계속 쌓아 관리하기 어렵다.
- 좋은 경기나 시즌 종료 시점에 전체 기록을 다시 확인하려면 직접 계산해야 한다.
- 기록 입력 자체보다, 입력한 기록이 계속 누적 관리되지 않는 점에서 더 큰 불편을 느낀다.

## Target User

v1의 대상은 `개인 선수` 한 명이다.

### Included User

- 사회인 야구 선수 개인
- 타자와 투수 모두 포함
- 공식 기록이 있는 경기와 없는 경기를 모두 직접 관리하려는 사람

### Excluded User

- 팀 관리자
- 팀 기록 담당자
- 감독
- 리그 운영자
- 다른 선수 기록을 대신 관리하려는 사용자

## Non-negotiable Product Rules

- 계정 1개는 선수 프로필 1개와 연결된다.
- 사용자는 자신의 기록만 관리한다.
- v1은 팀 또는 다중 선수 프로필 관리 모델을 지원하지 않는다.
- 모든 대표 시나리오와 화면 흐름은 `개인 선수 본인` 시점에서 작성한다.
- Google 계정 1개는 앱 계정 1개와 연결된다.
- 서로 다른 Google 계정은 서로 다른 앱 계정으로 취급한다.
- v1은 계정 연결과 계정 병합을 지원하지 않는다.

## Core Value

사용자는 이 서비스에서 아래 가치를 느껴야 한다.

1. 내 야구 기록이 한곳에 계속 쌓인다.
2. 이번 시즌 성적을 쉽게 확인할 수 있다.
3. 흩어진 기록을 다시 계산하지 않아도 된다.

## Product Positioning

제품의 성격은 아래처럼 정리한다.

- 핵심 문제: 흩어진 기록을 한곳에 모아 시즌 성적을 쉽게 확인하기 어렵다.
- 핵심 가치: 내 야구 기록을 계속 모으고 관리할 수 있다.
- 기본 진입 경험: 기록 확인
- 대표 재방문 순간:
  - 경기 직후 좋은 기록을 남기고 싶을 때
  - 시즌 중간에 현재 성적이 궁금할 때
  - 시즌이 끝나갈 때 전체 기록을 정리하고 싶을 때
- 장기 유지 동기:
  - 몇 경기 이상 기록이 쌓인 뒤 시즌 성적이 정리되어 보이는 경험
  - 시즌과 통산 기록이 끊기지 않고 이어진다는 감각

판단이 갈릴 때는 `입력 속도`보다 `기록 관리의 명확성`을 우선한다.

## Usage Context

모바일 웹 사용 맥락은 아래 세 가지를 모두 고려한다.

1. 경기 직후 현장에서 빠르게 기록 입력
2. 시즌 중간에 다시 접속해 현재 성적 확인
3. 나중에 다시 접속해 누락 경기 입력과 시즌 성적 정리

다만 기본 홈은 온보딩 전용 화면이 아니라 `기록 확인 요약 화면`이다.
데이터가 없는 첫 상태에서도 0 지표를 포함한 빈 기록 화면을 보여주고,
그 안에서 `경기 추가` 행동으로 연결한다.

## Platform

v1의 목표 플랫폼은 `모바일 웹`이다.

이는 단순히 화면 크기만 줄인 반응형 웹이 아니라,
문서와 설계가 아래 제약을 기본 전제로 가져간다는 의미다.

- 스마트폰 세로 화면 기준으로 핵심 흐름을 먼저 설계한다.
- 작은 화면에서도 기록 확인과 입력이 모두 가능해야 한다.
- 한 손 사용과 짧은 집중 시간에 대응해야 한다.
- 네트워크 불안정, 화면 이탈, 입력 중단 같은 상황을 고려해야 한다.
- 데스크톱은 모바일 구조를 확장해 보여줄 수는 있지만, 별도 핵심 제품 구조를 만들지 않는다.

## Primary Scenarios

v1은 하나의 단일 사용 순간만을 위해 설계하지 않는다.
대표적인 사용 시나리오는 아래 3가지다.

1. 시즌이 어느 정도 진행된 뒤 현재 성적이 궁금해져 기록 확인 요약 화면을 여는 경우
2. 좋은 경기 직후 기록을 남기기 위해 `경기 추가`로 들어가는 경우
3. 시즌이 끝나갈 때 누락된 경기들을 정리하며 전체 시즌 기록을 완성하는 경우

이 흐름에서 사용자가 느껴야 하는 핵심은 아래와 같다.

- 기록이 한곳에 쌓이고 있다.
- 시즌 성적이 점점 정리되고 있다.
- 기록 입력은 귀찮지만, 입력 후 보는 누적 결과가 그 수고를 정당화한다.

## Scenario Flow

1. 사용자가 서비스를 방문한다.
2. 인증 화면에서 구글 로그인을 진행한다.
3. 로그인 후 기본 진입 화면인 기록 확인 요약 화면으로 이동한다.
4. 기록이 없어도 0 지표를 포함한 빈 기록 요약 화면 구조가 먼저 보인다.
5. 사용자는 이번 시즌 핵심 지표를 확인한다.
6. 필요하면 `기록 보기`를 눌러 상세 기록 화면으로 들어가 더 많은 지표를 확인한다.
7. 새 경기 기록을 남기려면 `경기 추가`를 눌러 경기 입력 흐름으로 이동한다.
8. 경기 정보를 입력한다.
9. 타자 기록과 투수 기록 중 필요한 항목을 입력한다.
10. 저장 후 다시 기록 확인 요약 화면으로 돌아온다.
11. 누적된 시즌 기록을 확인한다.

이 기본 흐름은 아래 순간에도 그대로 재사용된다.

- 시즌 중간 확인: 기록 확인 요약 화면을 바로 열어 현재 시즌 지표를 보고, 필요하면 상세 기록 화면으로 들어간다.
- 경기 직후 입력: 기록 확인 요약 화면에서 곧바로 `경기 추가`로 이동한다.
- 시즌 마감 정리: 여러 날에 걸쳐 누락 경기들을 추가하며 시즌 기록을 완성한다.

## MVP Goals

- 구글 로그인 기반 인증
- 앱 내부 access token / refresh token 기반 세션
- 개인 선수 소유 경기 생성
- 타자 기록 입력
- 투수 기록 입력
- 시즌 기준 누적 기록 조회
- 통산 기준 누적 기록 조회
- 경기 유형 기준 필터 조회
- 빈 기록 화면 제공

## Included In V1

- 구글 로그인
- 로그아웃
- 토큰 재발급
- 원자적 경기 저장
- 한 경기에서 타자/투수 기록 선택 입력
- 이번 시즌 기록 조회
- 통산 기록 조회
- 경기 유형 필터
- 0 지표 기반 빈 상태 기록 화면
- 모바일 웹 기준 기본 화면/입력 흐름
- 입력 중 단계 전환 및 탭 전환 시 값 유지
- 화면 이탈 시 경고

## Excluded From V1

- 이메일/비밀번호 회원가입
- 이메일/비밀번호 로그인
- 계정 연결
- 계정 병합
- 팀 생성
- 선수 등록을 통한 로스터 관리
- 다중 선수 프로필 관리
- 타인 기록 대리 관리
- 팀 관리자/기록 담당자 기능
- 리그 운영 기능
- 외부 기록 자동 연동
- 최근 경기 전용 화면
- 경기 수정/삭제
- 타석별 상세 로그
- 이닝별 상세 로그
- 로컬 드래프트 완전 복구
- 커뮤니티 기능
- 영상 분석

## Locked Rules

- v1은 경기 생성만 지원한다.
- 로그아웃은 기록 확인 요약 화면 상단의 프로필 메뉴 안에 둔다.
- 타자 요약/대표 지표는 `경기수, 타수, 총안타, 타율, OPS`로 고정한다.
- 투수 요약/대표 지표는 `경기수, 이닝, ERA, WHIP, 삼진, 승`으로 고정한다.
- 타율과 OPS는 소수 셋째 자리까지 표시한다.
- ERA와 WHIP는 소수 둘째 자리까지 표시한다.
- 투수 이닝 표기는 `0.0 / 0.1 / 0.2` 형식을 사용한다.
- 0분모 비율 지표는 v1에서 `0.000` 또는 `0.00`으로 표기한다.

## Success Criteria

v1 문서는 아래 기준을 만족해야 한다.

- 제품이 개인 선수용 기록 관리 서비스로 명확하게 읽힌다.
- 핵심 가치는 `기록 확인과 누적 관리`로 일관된다.
- 모바일 웹 제약이 상위 문서에 반영된다.
- 경기 입력은 필수 행동이지만, 제품 정체성을 입력 앱처럼 만들지 않는다.
- 프론트엔드와 백엔드 구현 계획이 이 범위를 벗어나지 않는다.
