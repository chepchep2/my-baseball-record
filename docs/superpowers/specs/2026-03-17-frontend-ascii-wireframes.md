# Baseball Record V1 Frontend ASCII Wireframes

## Purpose

화면 기획서를 바탕으로 데스크톱 기준의 거친 레이아웃을 ASCII로 정리한다.  
이 문서는 시각 디자인 시안이 아니라, 화면별 정보 구조와 주요 액션 위치를 빠르게 맞추기 위한 와이어프레임 문서다.

## Included Screens

1. 로그인 화면
2. 회원가입 화면
3. 기록 확인 화면
4. 경기 생성 및 기록 입력 화면

---

## 1. 로그인 화면

```text
+--------------------------------------------------------------------------------------+
| Baseball Record                                                        [로그인][회원가입] |
+--------------------------------------------------------------------------------------+
|                                                                                      |
|                               +----------------------------------+                   |
|                               |              로그인                |                   |
|                               +----------------------------------+                   |
|                               | 이메일                             |                   |
|                               | [ user@example.com____________ ] |                   |
|                               |                                  |                   |
|                               | 비밀번호                           |                   |
|                               | [ ********____________________ ] |                   |
|                               |                                  |                   |
|                               | [ 상단 에러 배너 영역_________ ]     |                   |
|                               |                                  |                   |
|                               |         [ 로그인 버튼 ]             |                   |
|                               |                                  |                   |
|                               | 처음인가요? [회원가입으로 이동]         |                   |
|                               +----------------------------------+                   |
|                                                                                      |
+--------------------------------------------------------------------------------------+
```

### Notes

- 기본 진입 탭은 `로그인`
- 필드 에러는 각 입력 필드 아래
- 인증 실패 메시지는 상단 배너에 표시

## 2. 회원가입 화면

```text
+--------------------------------------------------------------------------------------+
| Baseball Record                                                        [로그인][회원가입] |
+--------------------------------------------------------------------------------------+
|                                                                                      |
|                             +--------------------------------------+                 |
|                             |              회원가입                  |                 |
|                             +--------------------------------------+                 |
|                             | 이름                                  |                 |
|                             | [ 조상우__________________________ ]   |                 |
|                             |                                      |                 |
|                             | 이메일                                 |                 |
|                             | [ user@example.com________________ ] |                 |
|                             |                                      |                 |
|                             | 비밀번호                               |                 |
|                             | [ Passw0rd!______________________ ]  |                 |
|                             |                                      |                 |
|                             | 비밀번호 확인                           |                 |
|                             | [ Passw0rd!______________________ ]  |                 |
|                             |                                      |                 |
|                             | [ 상단 에러 배너 영역____________ ]      |                 |
|                             |                                      |                 |
|                             |         [ 회원가입 버튼 ]               |                 |
|                             |                                      |                 |
|                             | 이미 계정이 있나요? [로그인으로 이동]        |                 |
|                             +--------------------------------------+                 |
|                                                                                      |
+--------------------------------------------------------------------------------------+
```

### Notes

- 이름, 이메일, 비밀번호, 비밀번호 확인 입력
- 비밀번호 규칙 미충족과 비밀번호 확인 불일치는 필드 아래에 표시
- 이미 가입된 이메일은 상단 배너에 표시

## 3. 기록 확인 화면

```text
+--------------------------------------------------------------------------------------+
| Baseball Record                                                    [경기 추가] [로그아웃] |
+--------------------------------------------------------------------------------------+
| 이번 시즌 기록                                                                          |
| 여러 출처의 기록을 한 화면에서 통합해서 확인                                                    |
+--------------------------------------------------------------------------------------+
| [이번 시즌]            [타자 | 투수]            [전체][리그][비공식 경기] [연도].               |
+--------------------------------------------------------------------------------------+
|                                                                                      |
|  +------------------+  +------------------+  +------------------+  +---------------+ |
|  | 경기수             |  | 타석 / 이닝        |  | 안타 / 실점        |  | 타율 / ERA     | |
|  | 24               |  | 88               |  | 31               |  | .352          | |
|  +------------------+  +------------------+  +------------------+  +---------------+ |
|                                                                                      |
|  +------------------+  +------------------+  +------------------+  +---------------+ |
|  | 출루율 / WHIP      |  | 장타율 / K/9      |  | OPS / 피안타율      |  | 홈런 / 삼진     | |
|  | .410             |  | .488             |  | .898             |  | 3             | |
|  +------------------+  +------------------+  +------------------+  +---------------+ |
|                                                                                      |
+--------------------------------------------------------------------------------------+
| 상세 지표                                                                              |
+--------------------------------------------------------------------------------------+
| 1루타 12    2루타 5    3루타 1    홈런 3    볼넷 9    삼진 7    사구 2                       |
| 타점 18     득점 14    도루 4     도루자 1  희생타 2                                        |
|                                                                                      |
| 투수 보기일 때는 같은 위치에 자책 / 실점 / 피안타 / 볼넷 / 사구 / 상대한 타자 수 등 표시               |
+--------------------------------------------------------------------------------------+
| 기록이 아직 없어도 카드 구조는 유지하고 모든 수치는 0으로 표시                                      |
+--------------------------------------------------------------------------------------+
```

### Notes

- 기본 진입은 `이번 시즌 기록`
- 상단 우측에 `경기 추가`, `로그아웃`
- 시간 축, 기록 축, 경기 필터를 상단에 배치
- 요약 카드 + 상세 지표 구조

## 4. 경기 생성 및 기록 입력 화면

```text
+--------------------------------------------------------------------------------------+
| Baseball Record                                                          [저장] [취소] |
+--------------------------------------------------------------------------------------+
| 경기 기록 입력                                                                          |
| 경기 정보 입력 후, 타자 기록과 투수 기록을 필요한 만큼 입력                                       |
+--------------------------------------------------------------------------------------+

  1. 경기 정보
  +----------------------------------------------------------------------------------+
  | 날짜              | 경기 유형            | 시즌/연도                                  |
  | [ 2026-03-17___ ] | [ 리그 __________ ] | [ 2026___________ ]                     |
  |                                                                                  |
  | 소속 팀           | 상대 팀                                                         |
  | [ 레전드________ ] | [ 전설_______ ]                                                |
  |                                                                                  |
  | 메모                                                                              |
  | [ 오늘 경기 메모____________________________________________________________ ]      |
  +----------------------------------------------------------------------------------+
|                                                                            [ 다음 ] |
+-------------------------------------------------------------------------------------+

  2. 기록 입력
  +----------------------------------------------------------------------------------+
  | [ 타자 기록 | 투수 기록 ]                                                            |
  +----------------------------------------------------------------------------------+

  타자 기록 탭
  +----------------------------------------------------------------------------------+
  | 기본 항목                                                                          |
  | 타석 [ 4 ]   타수 [ 3 ]   1루타 [ 1 ]   2루타 [ 0 ]   3루타 [ 0 ]                     |
  | 홈런 [ 1 ]   볼넷 [ 1 ]   삼진 [ 1 ]   사구 [ 0 ]                                    |
  |                                                                                  |
  | [ 추가 기록 입력 ]                                                                  |
  |                                                                                  |
  | 펼친 후: 타점 [ 2 ]   득점 [ 1 ]   도루 [ 0 ]   도루자 [ 0 ]   희생타 [ 0 ]              |
  +----------------------------------------------------------------------------------+

  투수 기록 탭
  +----------------------------------------------------------------------------------+
  | 기본 항목                                                                          |
  | 정수 이닝 [ 3 ]   추가 아웃 수 [ 2 ]   실점 [ 1 ]   자책 [ 1 ]                          |
  | 피안타 [ 4 ]      볼넷 [ 2 ]            삼진 [ 5 ]                                   |
  |                                                                                  |
  | [ 추가 기록 입력 ]                                                                  |
  |                                                                                  |
  | 펼친 후: 사구 [ 0 ]   피홈런 [ 0 ]   상대한 타자 수 [ 18 ]                               |
  |         승 [ 0 ]    패 [ 0 ]         세이브 [ 0 ]   홀드 [ 1 ]                       |
  +----------------------------------------------------------------------------------+

| [ 탭 상단 에러 요약 메시지______________________________________________________ ]       |
|                                                                             [ 저장 ] |
+-------------------------------------------------------------------------------------+
```

### Notes

- 먼저 경기 정보 입력 후 `다음`
- 기록 입력은 `타자 기록` / `투수 기록` 탭 전환형
- 한쪽만 입력해도 저장 가능
- 추가 항목은 `추가 기록 입력` 버튼으로 펼침
- 저장 불가 사유는 탭 상단 메시지로 노출

---

## Summary

- 인증 화면은 탭 전환형으로 구성
- 기록 확인 화면은 `요약 카드 + 상세 지표` 구조
- 경기 입력 화면은 `경기 정보 -> 기록 입력` 흐름
- 기록 입력 단계는 `타자 / 투수 탭` 전환형
