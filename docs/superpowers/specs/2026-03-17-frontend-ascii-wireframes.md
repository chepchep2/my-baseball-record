# Baseball Record V1 Frontend ASCII Wireframes

## Purpose

화면 기획서를 바탕으로 `모바일 웹 기준`의 거친 레이아웃을 ASCII로 정리한다.

이 문서는 시각 디자인 시안이 아니라,
작은 화면에서 어떤 정보가 먼저 보이고 어떤 행동이 어디에 놓여야 하는지 빠르게 맞추기 위한 와이어프레임 문서다.

## Included Screens

1. 인증 화면
2. 기록 확인 요약 화면
3. 상세 기록 화면
4. 경기 생성 및 기록 입력 화면

---

## 1. 인증 화면

```text
+--------------------------------------+
| My Baseball Record                   |
+--------------------------------------+
| 구글 로그인                          |
|                                      |
| [ 상단 에러 배너 영역____________ ]   |
|                                      |
| 내 기록을 계속 모으고 관리하세요      |
|                                      |
| [ Google로 계속하기 ]                |
+--------------------------------------+
```

### Notes

- 이메일/비밀번호 폼은 없음
- 구글 로그인 단일 행동 제공
- 인증 실패 메시지는 상단 배너에 표시

## 2. 기록 확인 요약 화면

```text
+--------------------------------------+
| 시즌 기록                            |
| [ 2026 시즌 ]              [ 경기 추가 ] |
+--------------------------------------+
| [ 타자 ] [ 투수 ]                     |
| [ 기록 보기 ]                         |
+--------------------------------------+
| 핵심 지표                             |
| +------------------+ +--------------+ |
| | 경기수           | | 타수         | |
| | 24               | | 88           | |
| +------------------+ +--------------+ |
| +------------------+ +--------------+ |
| | 총안타           | | 타율         | |
| | 31               | | .352         | |
| +------------------+ +--------------+ |
+--------------------------------------+
| | OPS              |                | |
| | .898             |                | |
+--------------------------------------+
| 현재 기준: 2026 시즌 / 전체 경기       |
+--------------------------------------+
| 기록이 없어도 0 지표 구조는 유지됨     |
```


### Notes

- 기본 홈은 `기록 확인 요약 화면`
- 첫 화면 우선순위는 `핵심 지표 -> 경기 추가 -> 기록 보기`
- 빈 상태에서도 기록 요약 화면 구조 유지
- `경기 추가`는 상단의 주요 행동으로 우선 배치
- `로그아웃`은 상단 고정 버튼으로 두지 않고 기록 요약 화면 하단의 저강도 영역에 둔다
- 타자와 투수 모두 같은 수준으로 기록 화면 예시를 제공
- 상세 필터와 상세 지표는 `기록 보기` 화면에서 본다

## 3. 상세 기록 화면

```text
+--------------------------------------+
| 상세 기록                            |
+--------------------------------------+
| [ 시즌 ] [ 통산 ] [ 2026 시즌 선택 ]  |
| [ 전체 ] [ 리그 ] [ 비공식 경기 ]     |
| [ 타자 ] [ 투수 ]                     |
+--------------------------------------+
| 대표 지표                             |
| 경기수 24   타수 88                  |
| 총안타 31   타율 .352               |
| OPS .898                            |
+--------------------------------------+
| 상세 지표                             |
| 타석 96      타수 88                 |
| 총안타 31    홈런 3                  |
| 타점 18      득점 14                 |
| 1루타 12     2루타 5                 |
| 3루타 1      도루 4                  |
| 도루자 1     희생타 2                |
| 볼넷 9       사구 2                  |
| 삼진 7                               |
+--------------------------------------+
| [ 뒤로 ]                             |
+--------------------------------------+
```

### 투수 상세 기록 예시

```text
+--------------------------------------+
| 상세 기록                            |
+--------------------------------------+
| [ 시즌 ] [ 통산 ] [ 2026 시즌 선택 ]  |
| [ 전체 ] [ 리그 ] [ 비공식 경기 ]     |
| [ 타자 ] [ 투수 ]                     |
+--------------------------------------+
| 대표 지표                             |
| 경기수 18   이닝 46.2                |
| ERA 2.57   WHIP 1.11                 |
| 삼진 41    승 4                      |
+--------------------------------------+
| 상세 지표                             |
| 승 4         패 2                    |
| 홀드 3       세이브 1                |
| 이닝 46.2    상대한 타자 수 188      |
| 피안타 33    피홈런 1                |
| 탈삼진 41    볼넷 19                 |
| 사구 2       실점 15                 |

+--------------------------------------+
| [ 뒤로 ]                             |
+--------------------------------------+
```

### Notes

- 요약 화면보다 더 많은 필터와 지표를 보여준다
- 모바일에서는 `요약 먼저, 상세는 별도 화면`으로 깊이를 나눈다
- 이 화면은 개별 경기 상세가 아니라 누적 기록 상세를 보여준다
- `리그 전체`, `팀 전체` 같은 범위는 v1에 포함하지 않는다

## 4. 경기 생성 및 기록 입력 화면

### 4-1. 경기 정보 입력 단계

```text
+--------------------------------------+
| 경기 기록 입력                        |
+--------------------------------------+
| 날짜                                 |
| [ 2026-03-02_____________________ ]  |
| [ 필드 에러______________________ ] |
|                                      |
| 경기 유형                             |
| [ 리그____________________________ ] |
| [ 필드 에러______________________ ] |
|                                      |
| [ 선택 정보 더 입력하기 ]              |
| 펼친 후:                             |
| 시즌/연도 [ 2026 ]                   |
| 소속 팀 [ 레전드 ]                   |
| 상대 팀 [ 블루스톰 ]                 |
| 메모 [ 시즌 초반 경기 메모 ]         |
+--------------------------------------+
| [ 취소 ]                    [ 다음 ] |
+--------------------------------------+
```

### 4-2. 기록 입력 단계

```text
+--------------------------------------+
| 경기 기록 입력                        |
+--------------------------------------+
| [ 타자 기록 ] [ 투수 기록 ]           |
+--------------------------------------+
| [ 상단 에러 요약__________________ ] |
+--------------------------------------+
| 기회                                 |
| 타석 [ 4_________________________ ]  |
| 타수 [ 3_________________________ ]  |
+--------------------------------------+
| [ 이전 묶음 ]              [ 다음 묶음 ]|
+--------------------------------------+
| 타자 기록 입력 완료 후 저장 가능       |
| 투수 기록은 선택 입력입니다            |
+--------------------------------------+
| [ 뒤로 ]                    [ 저장 ] |
+--------------------------------------+
```

### 투수 기록 탭 예시

```text
+--------------------------------------+
| [ 타자 기록 ] [ 투수 기록 ]           |
+--------------------------------------+
| 이닝                                 |
| 이닝 [ 3_________________________ ]  |
| 추가 아웃 수 [ 2__________________ ] |
+--------------------------------------+
| [ 이전 묶음 ]              [ 다음 묶음 ]|
+--------------------------------------+
| 투수 기록 입력 완료 후 저장 가능       |
| 타자 기록은 선택 입력입니다            |
+--------------------------------------+
| [ 뒤로 ]                    [ 저장 ] |
+--------------------------------------+
```

### Notes

- 먼저 `경기 정보` 입력 후 `기록 입력` 단계로 이동
- 기록 입력은 `타자 기록 / 투수 기록` 탭 전환형
- 한쪽만 입력해도 저장 가능
- 탭 전환과 단계 전환 시 값 유지
- 입력 중 이탈하려 하면 경고 제공
- 저장 실패 시 값 유지 후 재시도 가능
- 기록 입력 단계는 `한 번에 한 필드`보다 `한 번에 한 묶음`에 집중하는 구조
- `취소`는 전체 입력 중단, `뒤로`는 이전 단계 이동이며 값 유지
- 당일 경기 입력뿐 아니라 과거 경기 정리 입력 예시도 포함
- 시즌 정리 흐름은 별도 화면을 추가하기보다 일반 기록 확인 화면 안에서 자연스럽게 이어진다

### 저장 실패 상태 예시

```text
+--------------------------------------+
| 저장 실패                            |
+--------------------------------------+
| 저장에 실패했습니다                   |
| 입력값은 유지되며 다시 시도할 수 있습니다 |
+--------------------------------------+
| [ 입력으로 돌아가기 ]   [ 다시 시도 ] |
+--------------------------------------+
```

## Summary

- 인증 화면은 구글 로그인 단일 진입형
- 기록 확인 요약 화면은 `핵심 지표 우선 + 경기 추가 + 기록 보기` 구조
- 상세 기록 화면은 필터와 상세 지표를 깊게 확인하는 별도 화면
- 빈 상태도 기록 화면 구조를 유지
- 경기 입력 화면은 `경기 정보 -> 기록 입력` 단계형
- 기록 입력 단계는 `타자 / 투수` 전환형
