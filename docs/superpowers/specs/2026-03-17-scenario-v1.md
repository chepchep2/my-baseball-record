# Baseball Record V1 User Scenarios

> **작성일**: 2026-03-17
> **제품**: My Baseball Record
> **유형**: 개인 선수 전용 모바일 웹 기록 관리 서비스

---

## Why This Document Exists

이 문서는 기능 목록을 다시 적는 문서가 아니다.
`어떤 사용자가 어떤 순간에 이 앱을 열고, 어디서 가치를 느끼고, 왜 계속 쓰게 되는가`를
사람 중심으로 정리하는 시나리오 문서다.

v1은 하나의 사람만 보는 제품이 아니지만,
대표적인 사용 맥락은 아래 3가지로 묶을 수 있다.

1. 시즌 중반에 현재 성적이 궁금한 사용자
2. 좋은 경기 직후 기록을 바로 남기고 싶은 사용자
3. 시즌이 끝나갈 때 전체 성적을 정리하고 싶은 사용자

이 세 시나리오는 모두 같은 제품 구조를 공유한다.

- 기본 홈은 기록 확인 요약 화면
- 입력은 핵심 행동이지만 제품의 얼굴은 기록 확인
- 사용자는 자기 기록만 관리
- 모바일 웹에서 짧게 열고 자주 확인

---

## Scenario 1: 시즌 중반의 확인 욕구

> **유형**: In-season Check-in
> **강도**: 중간 빈도 / 높은 유지 가능성

### 프로필

**김민준**, 31세, 직장인
주말마다 리그 경기와 친선 경기를 둘 다 뛴다.
타자 기록에 관심이 많고, 시즌 중간쯤 되면 늘 “올해 내가 어느 정도 하고 있지?”가 궁금해진다.

### 배경

6월 중순.
리그 경기 6경기, 비공식 경기 4경기 정도를 뛰었다.
공식 기록은 게임원에 남아 있고, 비공식 경기는 카톡방 사진과 개인 메모에 흩어져 있다.

민준은 이번 시즌 타율이 체감상 좋아진 것 같은데,
정작 전체 기준으로는 얼마나 잘하고 있는지 알 수 없다.

### Day 0 - 확인하고 싶은 밤

일요일 밤, 잠들기 전에 문득 시즌 성적이 궁금해진다.

민준의 심리:
`요즘 잘 치는 것 같은데, 공식 경기만 보면 좀 애매하고 비공식 경기까지 합치면 느낌이 다를 것 같은데?`

앱을 연다.
Google 로그인 후 바로 기록 확인 요약 화면으로 들어간다.

화면에는 이번 시즌 기록 요약이 보인다.
리그 경기만이 아니라 자신이 직접 넣어둔 비공식 경기까지 합쳐 볼 수 있다.

민준은 여기서 처음으로
`아, 이 앱은 내가 친 경기들을 하나의 시즌으로 묶어서 보는 도구구나`
라고 이해한다.

### 제품의 Peak Moment

`앱 안에 모아둔 시즌 기록이 한 화면에서 같이 보이는 순간`

이 순간 민준은 단순히 숫자를 본 게 아니라,
자기 기록이 하나의 시즌으로 관리된다는 감각을 받는다.

여기서 중요한 점은 `외부 기록 자동 연동`이 아니라,
사용자가 앱 안으로 직접 정리해 넣은 기록이 하나의 시즌으로 이어져 보인다는 점이다.

필요하면 `기록 보기`를 눌러 상세 기록 화면으로 들어가 더 많은 지표를 확인할 수 있다.

### 다음 행동

기록 확인 요약 화면을 보다가, 아직 넣지 않은 친선 경기 2개가 생각난다.
상단의 `경기 추가`를 눌러 입력 화면으로 이동한다.

### 왜 계속 쓰게 되나

민준은 매일 입력하진 않더라도,
몇 경기만 더 쌓이면 기록 확인 요약 화면과 상세 기록 화면이 더 의미 있어진다는 걸 안다.

이 시나리오의 핵심은 `즉시 입력`보다 `누적 관리의 가치 인식`이다.

## Scenario 2: 좋은 경기 직후의 기록 보존 욕구

> **유형**: Post-game Capture
> **강도**: 높은 재방문 트리거 / 높은 이탈 위험

### 프로필

**박지훈**, 28세, 회사원
평소엔 기록에 꾸준하지 않지만, 잘한 경기는 꼭 남기고 싶어 한다.
특히 홈런이나 멀티히트 같은 타자 기록을 남겨두면 나중에 다시 보는 재미가 크다고 느낀다.

### 배경

토요일 오후 경기.
오늘 4타수 3안타 1홈런으로 정말 잘했다.
리그 경기라 공식 기록도 남겠지만, 지훈은 오늘 기분과 함께 자기 식으로 기록을 남기고 싶다.

### 경기 직후 - 주차장 안

차에 타기 전 휴대폰을 꺼낸다.

지훈의 심리:
`오늘 경기는 나중에 꼭 다시 보고 싶다. 지금 안 적으면 또 까먹는다.`

앱을 열고 기록 확인 요약 화면으로 들어간다.
상단의 `경기 추가`를 누른다.

경기 정보 입력 단계에서 날짜와 경기 유형을 넣는다.
그다음 기록 입력 단계로 가서 타자 기록만 입력한다.
투수 기록은 비워둔다.

저장을 누른다.

### 제품의 Peak Moment

저장 후 다시 기록 확인 요약 화면으로 돌아왔을 때,
방금 경기의 결과가 이번 시즌 기록에 반영되어 보이는 순간.

지훈의 심리:
`오, 그냥 메모한 게 아니라 시즌 기록에 바로 붙네.`

### 이탈 위험

이 시나리오는 재방문 트리거는 강하지만 이탈 위험도 크다.

- 입력이 길면 귀찮아서 포기
- 저장이 실패하면 다시 입력하기 싫어짐
- 값이 날아가면 신뢰가 깨짐

그래서 이 시나리오는 제품 전체의 얼굴은 아니지만,
서비스가 습관으로 굴러가게 만드는 엔진 역할을 한다.

### 왜 계속 쓰게 되나

처음에는 “오늘 경기 기록 보관”이 목적이었지만,
몇 번 반복하면 지훈도 시즌 전체를 보게 된다.

즉 입력 동기는 순간적이지만,
유지 동기는 결국 누적 기록 확인으로 넘어간다.

### 같은 순간의 투수 서브케이스

같은 주말 경기에서 투수로 5이닝 1실점 7삼진을 기록한 사용자는
타자처럼 홈런이나 멀티히트를 남기는 감각은 아니더라도,
`오늘 던진 경기 내용을 시즌 기록으로 남겨두고 싶다`는 동기로 같은 흐름을 탄다.

즉 경기 직후 입력은 타자만의 동기가 아니라,
투수에게도 충분히 강한 재방문 계기가 될 수 있다.

## Scenario 3: 시즌 마감의 전체 정리 욕구

> **유형**: Season Wrap-up
> **강도**: 높은 전환 가능성 / 높은 가치 체감

### 프로필

**최성호**, 35세, 직장인
사회인 야구를 오래 했고 주로 투수로 뛴다.
매 시즌이 끝날 때마다 “올해 공이 얼마나 통했나”를 꼭 돌아본다.
하지만 공식 기록만으로는 자기가 던진 전체 시즌을 설명할 수 없다고 느낀다.

### 배경

11월 초.
리그는 사실상 끝났고, 친선 경기 몇 개만 더 남았다.
성호는 투수 시즌을 정리하고 싶다.

게임원에는 리그 기록이 있지만,
비공식 경기와 연습 경기에서 던진 기록은 따로 모아둔 사진과 메모에 있다.

성호의 심리:
`맨날 시즌 끝나면 ERA랑 이닝이랑 삼진을 다시 계산한다. 올해는 좀 한 번에 보고 싶다.`

### Day 0 - 시즌 정리 시작

앱을 연다.
Google 로그인 후 기록 확인 요약 화면에서 이번 시즌 기록을 본다.

아직 누락된 경기가 꽤 있다는 걸 안다.
그래도 화면 구조가 먼저 보여서
`이 자리에 내 시즌이 채워질 거구나`
라는 기대를 갖는다.

성호는 하나씩 경기를 추가하기 시작한다.
리그 경기든 비공식 경기든 구분해서 넣고, 투수 기록을 중심으로 입력한다.

### 시즌 마감의 감정적 계기

성호에게 이 과정은 단순한 정리만은 아니다.
시즌 중 가장 잘 던졌던 경기, 삼진이 많이 잡혔던 경기, 위기를 막아낸 경기들을
올해 시즌의 일부로 다시 붙여두는 감각이 있다.

그래서 투수 시나리오도 `회고만 하는 사용자`가 아니라
`좋았던 투수 시즌을 자기 방식으로 남기고 싶은 사용자`로 봐야 한다.

### 며칠에 걸친 정리

성호는 하루에 모든 경기를 다 넣지 않는다.
퇴근 후 2~3경기씩 나눠서 입력한다.

입력할수록 기록 확인 요약 화면과 상세 기록 화면의 숫자가 조금씩 바뀐다.
이닝, 삼진, WHIP, ERA, 경기수가 쌓여간다.

### 제품의 Peak Moment

모든 시즌 경기를 거의 정리한 뒤,
리그와 비공식 경기를 합친 자기 투수 시즌 성적이 한 화면에 정리되어 보이는 순간.

성호의 심리:
`이게 내가 뛰었던 올해 시즌이구나.`

이 순간은 단순한 통계 확인이 아니라,
자기 시즌을 회고하고 보관하는 경험에 가깝다.

### 왜 계속 쓰게 되나

성호는 시즌이 끝나고서야 앱의 진짜 가치를 크게 느낀다.

- 흩어진 투수 기록이 하나로 모임
- 시즌과 통산 기록이 자연스럽게 이어짐
- 다음 시즌에도 계속 쌓아보고 싶음

이 시나리오는 v1의 핵심 가치를 가장 강하게 설명한다.

## Three-scenario Summary

### 공통점

- 모두 개인 선수 시점이다.
- 모두 기록 확인 요약 화면이 기준 화면이다.
- 입력은 중요하지만 기록 확인 가치에 종속된다.
- 기록이 쌓일수록 앱의 가치가 커진다.

### 차이점

- 시나리오 1은 `시즌 중간 점검`
- 시나리오 2는 `경기 직후 입력`
- 시나리오 3은 `시즌 전체 정리`

### Product Interpretation

이 3개를 같이 보면 v1은 아래처럼 해석된다.

- 재방문을 가장 직접적으로 만드는 행동: 경기 후 입력
- 사용자가 계속 남게 만드는 가치: 기록 누적 관리
- 제품의 핵심 얼굴: 시즌 기록 확인

---

## Not Covered In These Scenarios

- 팀 공동 입력
- 다른 선수 기록 대리 관리
- 최근 경기 전용 화면
- 외부 기록 자동 연동
- 상세 타석 로그 입력
- 이닝별 상세 로그 입력
