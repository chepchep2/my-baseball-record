# Entry Calendar Real Month Layout Design

## 목적

입력 플로우 1단계의 날짜 달력을 실제 달력처럼 보이게 바꾼다.
현재는 선택한 달의 날짜가 `1`부터 순서대로만 배치되어 실제 달력의 시작 요일과 맞지 않는다.

이번 변경의 목표는 다음과 같다.

- 월 시작 요일을 실제 달력과 맞춘다.
- 달력을 항상 `7열 x 6행` 구조로 고정한다.
- 앞달/다음달 날짜를 흐리게 보여 실제 월간 달력처럼 읽히게 한다.
- 앞달/다음달 날짜를 탭하면 해당 월로 이동하면서 날짜를 선택할 수 있게 한다.
- 미래 날짜는 현재 규칙대로 계속 선택 불가 상태를 유지한다.

## 적용 대상

- `frontend/src/features/entry/components/EntryCalendarSheet.jsx`
- 관련 스타일
- 관련 테스트

## 설계

### 구조

- 상단 연월 표시와 연월 선택 UI는 유지한다.
- 요일 행을 달력 본문 위에 고정해서 보여준다.
- 날짜 셀은 항상 42칸(`7열 x 6행`)으로 렌더한다.

### 날짜 셀 규칙

- 현재 월 날짜:
  - 기본 상태
  - 선택 가능
- 이전달 날짜:
  - 흐리게 표시
  - 탭하면 이전달로 이동하면서 해당 날짜를 선택
- 다음달 날짜:
  - 오늘 또는 오늘 이전이면 흐리게 표시
  - 탭하면 다음달로 이동하면서 해당 날짜를 선택
  - 미래 날짜이면 disabled 유지

### 상태 표현

- `오늘`은 별도 강조한다.
- `선택일`은 오늘과 구분되는 강조를 사용한다.
- 미래 날짜는 현재처럼 disabled 스타일을 유지한다.
- 앞달/다음달 날짜는 현재 월 날짜보다 약하게 보이되 읽히지는 않아야 한다.

## 사용성 기대 효과

- 사용자가 실제 달력처럼 월의 시작 위치를 바로 이해할 수 있다.
- 월을 넘나드는 날짜 선택이 더 자연스러워진다.
- 월마다 높이가 흔들리지 않아 모바일에서도 안정적으로 보인다.
